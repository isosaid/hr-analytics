# HR-Analytics · Дашборд рекрутинга «Авесто Групп»

Веб-дашборд по подбору персонала компаний холдинга. Один файл `index.html`, без сервера и без внешних библиотек.

## Публикация

1. Создать репозиторий (например `hr-analytics`) на https://github.com/isosaid
2. Загрузить в него `index.html` и этот `README.md`
3. Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save
4. Через 1–2 минуты сайт открывается по адресу `https://isosaid.github.io/hr-analytics/`

## Вкладки

- **Дашборд Общий** — KPI, показатели по подразделениям, открытые вакансии с остатком, воронка по категориям, динамика по месяцам
- **Дашборд Подробный** — сроки закрытия, план/факт по категориям, просроченные вакансии
- **Сводная таблица** — все заявки, проверка качества данных (16 правил), правка ячеек, добавление и удаление строк
- **История** — журнал изменений, журнал входов, версии данных, пользователи, обновление из Google Sheets

## Роли

| Роль | Данные | Правка | Пользователи |
|---|---|---|---|
| Администратор | весь холдинг | да | да |
| Сотрудник Авесто | весь холдинг | да | нет |
| Компания | только своя | нет | нет |

## Обновление данных из Google Sheets

Вкладка «История» → «Источник данных · Google Sheets» → «Обновить данные».

Требования:
- таблица открыта «Все, у кого есть ссылка» с ролью «Читатель»
- дашборд открыт по адресу `https://` (с локального диска браузер блокирует запрос)

Заголовки колонок распознаются по названиям, порядок столбцов значения не имеет.

## Хранение

Правки, журналы, версии и учётные записи хранятся в браузере (localStorage) — у каждого компьютера свои.
Журналы можно свести вручную: «Выгрузить журналы» на одном ПК → «Загрузить журнал с другого ПК» на другом.

Защита паролем — клиентская: она предохраняет от случайного доступа, но не является настоящей защитой,
поскольку код страницы доступен любому, кто её открыл.
